# GS8 Triple 2.0

Базовый проект для GAC GS8 Gen2 / Android 9.

## В этой версии
- Выбор двух или трёх приложений.
- Режим 2 окон с начальной шириной 960/960.
- Режим 3 окон с начальной раскладкой 400/760/760.
- Запрос Freeform через скрытый `ActivityOptions.setLaunchWindowingMode(5)`.
- Сохранение выбранных приложений и размеров.
- Экспериментальная плавающая панель для изменения желаемых размеров.

## Ограничения
- Freeform зависит от реализации прошивки.
- Обычное приложение Android не имеет публичного API для изменения границ уже работающей чужой задачи и удаления системных заголовков окон.
- Плавающая панель в этой исходной версии сохраняет размеры; для применения нужно вернуться в GS8 Triple и нажать «Разложить окна».
- Это стартовая реализация, не подтверждённая на автомобиле. APK собирается через GitHub Actions.
